# 🗄️ Estudos SQL

Repositório dedicado aos meus estudos práticos em **SQL e bancos de dados relacionais**, desenvolvido durante minha jornada de aprendizado em Tecnologia da Informação.

## 🎯 Objetivo

Praticar os fundamentos de bancos de dados, compreender a organização de tabelas e desenvolver conhecimentos em consultas e manipulação de dados.

## 🛠️ Tecnologias utilizadas

- **MySQL** — sistema de gerenciamento de banco de dados.
- **SQL** — linguagem utilizada para definir, consultar e manipular dados.
- **MySQL Workbench** — ferramenta utilizada para trabalhar com o banco de dados.

## 📂 Conteúdo do repositório

- Arquivo SQL com a estrutura e os comandos desenvolvidos durante os estudos.
- Exercícios e práticas de banco de dados realizados em aula.

## 📚 Conhecimentos em desenvolvimento

- Criação e estruturação de bancos de dados.
- Criação de tabelas e definição de campos.
- Consultas e manipulação de dados.
- Relacionamentos entre tabelas.
- Organização e modelagem de dados relacionais.

## 🚀 Sobre o projeto

Este projeto faz parte do meu portfólio de estudos em TI e representa minha evolução no aprendizado de SQL e gerenciamento de bancos de dados.

O repositório será atualizado conforme eu desenvolver novos exercícios e adquirir conhecimentos.
